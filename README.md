## Descrição do Projeto
Este projeto consiste na criação de uma pintura artística inspirada no estilo de Piet Mondrian utilizando apenas HTML e CSS.
O objetivo principal é aplicar conceitos de Grid Layout e Flexbox para estruturar e estilizar a página.

## Funcionalidades
Implementação de um layout responsivo usando CSS Grid.
Utilização de Flexbox para alinhamento e distribuição dos elementos.
Design minimalista inspirado nas obras de Mondrian, com formas geométricas e cores primárias.

## Tecnologias Utilizadas
**HTML5:** Estruturação do conteúdo da página.
**CSS3:** Estilização e criação do layout usando Grid e Flexbox.

## Objetivos do Projeto
Praticar habilidades de layout com Grid e Flexbox.
Criar uma representação artística utilizando apenas HTML e CSS.
Aperfeiçoar técnicas de design responsivo.
